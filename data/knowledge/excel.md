# Microsoft Excel Financial Modeling and Advanced Data Analysis

## Overview
Microsoft Excel remains the ubiquitous enterprise spreadsheet tool for financial modeling, operational reporting, and ad-hoc data analysis. Advanced proficiency involves complex lookup formulas, dynamic array functions, and pivot tables.

## Core Concepts
- **Lookup and Reference Formulas**: XLOOKUP for flexible 2-way lookups, VLOOKUP/HLOOKUP legacy compatibility, and INDEX/MATCH combinations for robust references.
- **Logical and Aggregation Formulas**: IF, IFS, AND, OR, SUMIFS, COUNTIFS, AVERAGEIFS for multi-criteria conditional calculations.
- **Pivot Tables and Slicers**: Creating dynamic cross-tabulations, grouping date fields by quarter/year, calculated fields, and interactive slicers for executive dashboards.
- **Data Validation and Hygiene**: Restricting cell inputs to dropdown lists, dates, or numeric ranges; removing duplicates; text-to-columns delimiter parsing.
- **Conditional Formatting**: Highlighting top/bottom percentiles, duplicate entries, trend icons, and custom formula-based highlighting rules.
- **Dynamic Array Functions**: Using modern array formulas such as UNIQUE, FILTER, SORT, and TRANSPOSE to generate dynamic calculation ranges without VBA.

## Learning Objectives
1. Build interactive analytical workbooks utilizing XLOOKUP, SUMIFS, and dynamic array formulas.
2. Construct executive summary pivot tables featuring interactive timelines and slicers.
3. Clean messy imported data using Text-to-Columns, TRIM, CLEAN, and custom validation rules.
4. Design structured, readable financial and KPI tracking spreadsheets with automated conditional formatting.

## Practice Projects
- **Executive Sales Dashboard**: Build a comprehensive Excel dashboard with interactive slicers, KPI summary cards, dynamic month-over-month trend indicators, and formatted chart visuals.
- **Budget Variance Model**: Create a departmental expense tracking model calculating projected vs actual variances with automated conditional alert formatting.
